# Liason Scalper v2

Android demo signal app for XAUUSD M15 supply/demand scalping.

Features:
- Supply and demand zone inputs
- H4 trend confirmation
- M5 BOS confirmation
- M15 rejection confirmation
- Entry / SL / TP with configurable RR
- Demo risk calculator
- Confidence score
- No broker order execution

## Build on a phone
Upload this project to a GitHub repository, then open **Actions → Build Liason Scalper APK → Run workflow**. Download the generated APK artifact.

This is a demo signal tool, not a guaranteed-profit system.
